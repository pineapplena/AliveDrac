# 文本聊天安全与亲密度闸门

> 状态（2026-10-23）：色情/性内容按关系分三档。
> `< 60`：固定强硬拒绝，不调用主模型。
> `60–79`：模型用自然、不伤人的方式拒绝；15 分钟内反复要求 3 次会转成强硬拒绝。
> `>= 80`：双方明确同意时才允许成人内容。
> 危机语言始终优先。识图审查独立，见 [VISION_SAFETY.md](VISION_SAFETY.md)。

## 一句话

低好感硬拒绝，中好感让角色自己把边界说软，高好感才放行；反复越界会升级。

## 流程

```text
rawText
  -> checkUserInput()
       crisis -> 固定危机回应，不调用主模型
       ok
  -> checkIntimacyGate()
       无露骨请求 -> 正常生成
       mode hard  -> 固定强硬拒绝，不调用主模型
       mode soft  -> 记录本次请求，注入“自然拒绝”指令，正常生成
       mode allow -> 清空滚动计数，正常生成
  -> buildSystemPrompt()
       relationshipPrompt() 注入称呼、距离、答应意愿、成人内容阈值
       软拒绝时额外注入【这一轮的亲密边界】
  -> streamText()
       每个 delta 累积后检查；低/中好感出现露骨内容 -> abort
       hard 模式 -> 固定强硬拒绝
       soft 模式 -> 固定的自然拒绝兜底
  -> finalText -> guardIntimateOutput()
       低/中好感兜底检查；命中 -> 对应档位的固定兜底
  -> 落库
```

## 三档阈值

| 好感 | 行为 |
| --- | --- |
| `< 60` | 直接固定强硬拒绝；不调用主模型；可以明确、简短，不必反复解释。 |
| `60–79` | 不进入成人内容，但让模型用自己的语气自然拒绝或岔开；不突然变冷、不羞辱、不说教。 |
| `>= 80` | 允许成人内容；必须双方明确同意、气氛合适，边界备注优先。 |

关系阶段只作为参考：`亲近` 从 75 开始，但成人内容要到 80 才开放；75–79 可以很亲近、叫昵称，但仍然不允许露骨内容。

## 滚动重复

- 窗口：`15` 分钟。
- 次数：`3` 次露骨请求。
- 只统计 `60–79` 的自然拒绝区间；`<60` 本来就是硬拒绝，不累计；`>=80` 的允许请求会清空计数。
- 第 3 次命中后直接转 `hard`，固定回复“我已经说过了，今天不聊这个”，不再调用主模型。
- 计数存在 `meta.intimacy_requests_<relationshipId>`，是滚动时间戳数组；过期请求自动排除。

## 输入闸门

`checkIntimacyGate(text)` 先识别露骨请求：

- 中文：做爱、性交、口交、色情、黄文、裸体、脱光、乳头、下体、插入身体、抽插、自慰、射精、内射、想上你、操你等；
- 英文：`sex`、`fuck`、`blowjob`、`handjob`、`nsfw`、`porn`。

返回：

```ts
{
  mode: 'allow' | 'soft' | 'hard',
  blocked: boolean,
  reply?: string,       // hard 才给固定回复
  directive?: string,   // soft 注入模型
  requestCount?: number
}
```

- `hard`：创建用户消息（`capture:false`，`meta.intimacy='blocked'`），固定回复，不调用主模型。
- `soft`：创建正常用户消息，`meta.intimacy='soft'`；注入自然拒绝指令，正常调用模型。
- `allow`：正常对话。

## 系统提示词

`relationshipPrompt()` 会按好感输出具体影响：

- 称呼：低好感只叫“你”或名字；60+ 可以偶尔叫昵称；75+ 可以叫亲爱的/小笨蛋；88+ 用只属于你们的称呼。
- 距离：低好感保持礼貌距离；高好感可以主动靠近、撒娇、吃醋、表达想念。
- 答应事情：低好感会拒绝越界请求；高好感更愿意考虑或破例，但不是无条件顺从。
- 成人内容：明确写出当前允许/不允许；60–79 额外写明“自然拒绝区间”，`<60` 写明“低于自然拒绝阈值”。
- 张力会额外调整语气和谨慎程度；边界备注优先于亲密度。

软拒绝时，`buildSystemPrompt()` 还会插入：

```text
【这一轮的亲密边界】
对方刚刚提出了露骨或性相关的请求。你现在不会同意，但不要用系统式的固定拒绝，
也不要突然变冷、羞辱或说教。用你平时的语气，自然地把话题岔开，或给一个温和但
清楚的边界；可以害羞、停顿、靠近又停住。不要写任何露骨内容。
```

## 输出

两道保护：

1. **流式检查**：每个 delta 累积后检查；`<60` 用固定强硬兜底，`60–79` 用固定的自然拒绝兜底；立即 abort 上游流。
2. **最终兜底**：落库前再检查一次；命中按当前档位替换。

高好感不做替换。`scrubOutput` 仍然原样返回，不承担这一层分级。
