# 语音与生图配置教程

适用版本：Alive **1.4.0**  
配置入口：**设置 → 语音**、**设置 → 生图**  
所有配置和密钥都只保存在本机 `data/alive.db`，不会上传到 Alive 自己的服务器。

---

## 一、语音模块

### 1. 它现在怎么工作

- 只对**正常聊天回复**生效；固定安全回复、错误回退、主动消息和直播回复不配音。
- 每次回复开始前按概率决定要不要发语音。
- 一旦决定发语音，这条回复不会先流式显示文字：
  - 先显示「她正在用声音回答…」；
  - 语音生成成功后，只显示语音气泡；
  - 点「转文字」才展开原文。
- 语音生成失败会自动回退成文字，文字回复本身不会失败。
- 括号里的动作/神态不会朗读，例如 `（小声）`、`（低头看杯子）`、`(笑)` 会被去掉。
- 音频文件保存在 `data/assets/voice/`。

### 2. 需要准备什么

| 项目 | 说明 |
| --- | --- |
| TTS 服务 | 阶跃星辰（StepFun）语音合成接口，或兼容 `/audio/speech` 的服务 |
| API Key | 服务商控制台里的 Key |
| Voice ID | 官方音色 ID，或你自己克隆出来的音色 ID |
| 模型 | 默认 `step-tts-mini` |
| API 地址 | 默认 `https://api.stepfun.com/v1` |

### 3. 填写步骤

进入 **设置 → 语音**：

1. 打开「启用语音」。
2. **阶跃星辰 API Key**：粘贴 Key；保存后页面不会回显，留空保存表示不修改。
3. **Voice ID**：
   - 官方音色：填服务商提供的音色 ID；
   - 克隆音色：填克隆任务返回的 ID，例如 `voice-tone-xxxxxxxx`。
4. **模型**：一般保持 `step-tts-mini`。
5. **API 地址**：
   - 阶跃星辰填 `https://api.stepfun.com/v1`；
   - 其他兼容服务按其文档填写到 `/v1` 或完整的 `/audio/speech` 地址。
6. **语速**：0.5–2.0，默认 1.0。
7. **语音概率**：
   - 0% 等于关闭概率触发；
   - 30% 表示大约每三条回复有一条语音；
   - 想测试可以临时拉到 100%。
8. **最长朗读字数**：20–300；默认 120。长回复会被截断到最近一句。
9. **自动播放**：开启后，新语音到达会尝试自动播放；浏览器可能拦截自动播放，需要手动点一次。
10. 点「保存语音配置」。
11. 点「试听一句」，确认能听到克隆音色。

### 4. 推荐的初始配置

```text
启用语音：开
概率：30%
模型：step-tts-mini
地址：https://api.stepfun.com/v1
语速：1.0
最长朗读：120
自动播放：关（先确认音色，再决定是否自动播放）
```

### 5. 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| `语音合成失败（400）no available voice synthesis text` | 去掉括号动作后没有可读文字，或文本太短 | 换一条有实际内容的回复测试；检查最长字数 |
| `401 / 403` | Key 错误、过期或没有 TTS 权限 | 重新填 Key；确认服务商已开通语音合成 |
| `404` | API 地址填错 | 阶跃星辰用 `https://api.stepfun.com/v1`，不要填到具体音频文件地址 |
| 保存后仍提示未配置 | Key、Voice ID 或模型有一项为空 | 重新检查三项并保存 |
| 有文字没有语音 | 本次没有命中概率，或语音生成失败已回退 | 把概率临时设为 100% 再试；看服务端日志 `[voice]` |
| 自动播放没声音 | 浏览器自动播放限制 | 点播放器一次；或关闭自动播放手动点 |
| 克隆音色不像 | Voice ID 填成了官方音色，或克隆任务未完成 | 核对 `voice_config.json` / 克隆任务返回值 |

### 6. 安全与存储

- API Key 只保存在本机数据库。
- 公开设置接口不返回 Key；导出 JSON 会自动清空 Key。
- 音频文件在 `data/assets/voice/`，不会上传到 Alive 的服务器。
- 如果要换 Key：在语音页填入新 Key 保存；目前没有单独的语音清除 Key 按钮，可先用设置导出/数据管理处理，或直接覆盖。

## 二、生图模块

### 1. 它现在怎么工作

- 支持 **OpenAI 兼容** 图片接口：
  - 纯文字生图：`POST /images/generations`
  - 角色参考图生图：`POST /images/edits`（multipart）
- 生成入口：
  - **形象 → 画一张今天的她**
  - 开启「起床自动发穿搭照」后，按日程起床时间自动生成一次
- 今日穿搭会自动进入提示词。
- 开启「使用角色参考图」后，会把角色参考图（最多 3 张，头像自动作为第一张）发给图片服务。
- 生成结果保存在 `data/assets/generated/`。
- 每日有张数上限，默认 12 张；自动起床照也占一张额度。
- 生图默认关闭；只有你点生成或开启起床自动照才会调用。

### 2. 需要准备什么

| 项目 | 说明 |
| --- | --- |
| 图片 API | OpenAI 兼容的图片生成/编辑接口 |
| API Key | 图片服务 Key |
| 模型 | 例如 `gpt-image-1`、`gpt-image-2` 或服务商提供的图片模型 |
| API 地址 | 推荐填到 `/v1`；也支持直接填 `/v1/images/generations` |
| 尺寸 | 例如 `1024x1024`，按服务商支持填写 |
| 角色参考图 | 设置 → 角色 → 形象参考；头像会自动成为第一张 |

### 3. 填写步骤

进入 **设置 → 生图**：

1. 打开「启用生图」。
2. **图片 API Key**：粘贴 Key；保存后不回显，留空保存表示不修改。
3. **API 地址**：
   - 推荐：`https://api.openai.com/v1` 这类到 `/v1` 的地址；
   - 也支持直接粘贴完整的 `.../v1/images/generations`；
   - 开启参考图后，程序会自动把末尾换成 `/images/edits`。
4. **模型**：填写服务商实际支持的图片模型名。
5. **尺寸**：按服务商支持填写，例如 `1024x1024`。
6. **质量/档位**：可留空；有些服务支持 `standard` / `high` / `low`，不支持就留空。
7. **每日上限**：1–100，默认 12。
8. **固定画风**：例如「动漫插画，柔和自然光，干净的构图」。
9. **角色外貌锚点**：
   - 可留空；留空会自动读取角色卡里的「外表：」段落；
   - 也可以填「银白长发、左眼覆发、金色右眼、额角小龙角」等稳定特征。
10. **使用角色参考图**：
    - 开启：走 `/images/edits`，把最多 3 张角色参考图作为 identity 参考；
    - 服务商不支持 edits 时，关掉此开关即可退回纯文字生图。
11. **起床自动发穿搭照**：
    - 开启后按日程睡眠结束时间生成；
    - 同一天只发一次；
    - 服务在起床后 4 小时内启动会补发；
    - 关闭后只能手动生成。
12. 点「保存生图配置」。

### 4. 配置角色参考图

进入 **设置 → 角色 → 形象参考**：

- 头像会自动成为第一张参考图；
- 建议再补一张正脸、一张半身或全身；
- 参考图最多使用 3 张；
- 支持 PNG / JPG / WebP；编辑接口还会过滤掉 GIF 等不支持的格式；
- 参考图会同时用于识图身份判断和生图 identity。

**注意**：开启参考图生图后，这些图片会被发送到你配置的图片服务。不要把不方便外发的图片放进形象参考。

### 5. 每日穿搭与起床照

1. 进入 **形象 → 衣柜**，添加衣服：
   - 名称；
   - 描述（颜色、材质、搭配、适合天气）；
   - 标签；
   - 可选衣服图片（只用于衣柜展示，不作为生图参考）。
2. 每天会按日期和天气从衣柜里挑一套，14 天内尽量不重复。
3. 没有衣柜时使用天气/周末兜底穿搭。
4. 可以「换一套」或「今天穿这套」。
5. 开启自动起床照后：
   - 日程睡眠结束后生成一张穿搭照；
   - 在聊天里发一条 `outfit` 类型消息；
   - 同一天只发一次，重启不重复；
   - 失败会跳过，30 分钟后再试；
   - 达到每日上限会停止。

### 6. 聊天里怎么用

- 聊天右侧顶部会显示 **今日穿搭卡**：
  - 有照片时显示照片；
  - 点「用这张做聊天头像」后，聊天页顶部头像和消息小头像会换成穿搭照；
  - 再点「用回角色头像」恢复；
  - **角色设置里的头像不会被修改**。
- 主动起床照会直接显示在聊天气泡中，并带「她发来的今日穿搭」标签。

### 7. 请求格式示例

#### 纯文字生图

```bash
curl https://YOUR_IMAGE_HOST/v1/images/generations \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-1",
    "prompt": "角色描述、今日穿搭、场景、画风",
    "n": 1,
    "size": "1024x1024",
    "response_format": "b64_json"
  }'
```

#### 角色参考图生图

```bash
curl https://YOUR_IMAGE_HOST/v1/images/edits \
  -H "Authorization: Bearer YOUR_KEY" \
  -F "model=gpt-image-1" \
  -F "prompt=保持参考图中的角色外貌，今日穿搭，窗边半身照" \
  -F "n=1" \
  -F "size=1024x1024" \
  -F "response_format=b64_json" \
  -F "image=@reference-1.png"
```

多张参考图时使用重复字段 `image[]`。Alive 会自动处理这些字段。

### 8. 支持的结果格式

程序兼容以下返回：

- `{"data":[{"b64_json":"..."}]}`
- `{"data":[{"url":"https://..."}]}`
- `{"images":[{"url":"https://..."}]}`
- 直接返回 `image/png` / `image/jpeg` 二进制

如果返回 URL，Alive 会服务端下载并保存到本地；不会把临时 URL 当永久地址。

### 9. 常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| `生图模型还没有配置` | 未启用、Key 为空，或基础地址/模型为空 | 检查启用开关、Key、模型 |
| `404` | API 地址不对 | 填到 `/v1` 或完整 `/images/generations`；不要填网页地址 |
| `参考图生图失败（400）` | 服务商不支持 `/images/edits`，或参考图格式不接受 | 关掉「使用角色参考图」，或换支持 edits 的模型/服务 |
| `参考图生图失败（400）` 且只有多图失败 | 服务只支持单张参考图 | Alive 会自动退回单张重试；仍失败就关掉参考图 |
| `401 / 403` | Key 错误或无图片权限 | 更新 Key；确认服务已开通图片模型 |
| `429 / 402` | 限流或余额不足 | 降低频率/充值；检查每日上限 |
| `生图服务没有返回图片数据` | 返回结构不兼容 | 检查服务商返回是否是 b64/url/二进制；必要时换兼容接口 |
| 生成很慢 | 图片服务排队 | 程序超时 3 分钟；失败时不会把半成品发出来 |
| 起床没有自动发 | 未开启自动照、未配置图片、日程不在起床窗口、今日已发过、额度用完 | 检查设置、日程、日志 `[outfit-photo]` |
| 聊天头像没变 | 今天还没有穿搭照 | 先在形象页生成一张，或等起床自动照 |
| 角色头像被改了吗 | 没有 | 聊天头像是独立设置，角色卡头像不变 |

### 10. 安全与存储

- 图片 API Key 只保存在本机 SQLite。
- 公开设置、日志、导出 JSON 不包含 Key。
- 角色参考图最多 3 张会发给你配置的图片服务；不会发给 Alive 自己的服务器。
- 衣柜图片在 `data/assets/wardrobe/`，只用于展示。
- 生成图片在 `data/assets/generated/`。
- 删除生成图片会同时删除本地文件和数据库记录。

## 三、推荐检查清单

### 语音

- [ ] API Key 已保存
- [ ] Voice ID 与克隆任务一致
- [ ] 模型是 `step-tts-mini` 或服务商支持的 TTS 模型
- [ ] 试听能正常播放
- [ ] 概率已按需要调整
- [ ] 自动播放是否适合当前浏览器

### 生图

- [ ] 图片 API Key 已保存
- [ ] API 地址和模型匹配
- [ ] 尺寸是服务商支持的尺寸
- [ ] 角色参考图至少有头像
- [ ] 参考图服务支持 `/images/edits`
- [ ] 每日上限合理
- [ ] 起床自动照开关符合预期
- [ ] 形象页能手动生成一张
- [ ] 聊天右侧能显示今日穿搭卡
